
# DeepShield 🛡️

### Intelligent Network Intrusion Detection Using Deep Learning

An individual semester project focused on developing a deep-learning-based Network Intrusion Detection System (NIDS).

## Objectives

- Detect benign and malicious network traffic.
- Classify network attack categories.
- Compare deep learning architectures.
- Evaluate detection performance.
- Develop a network traffic analysis dashboard.

## Technology Stack

- Python
- PyTorch
- NumPy
- Pandas
- Scikit-learn
- JupyterLab
- FastAPI
- React
- MariaDB

## Dataset

CIC-IDS2017 (planned).
